# CYBERFORGE AI
### **Build Skills. Break Threats.**

---

### Executive Overview
**CyberForge AI** is a production-ready cybersecurity education platform and interactive cyber range powered by an embedded AI mentor named **AMAN**. It combines structured role-based learning tracks with in-browser practical labs, SIEM alert simulators, and automated flag verification to prepare students for real-world offensive and defensive security careers.

---

### Key Product Highlights
- **Role-Based Roadmaps**: Curated curricula for **SOC Analysts**, **Penetration Testers**, **Web Security Auditors**, and **CTF Competitors**.
- **Interactive Cyber Labs**: Zero-infrastructure, in-browser sandboxes for Linux CLI, Network Topologies & Subnetting, OWASP Web Security, and SOC Alert Triage.
- **Embedded AI Mentor (AMAN)**: 9 pedagogical modes (`TEACH`, `DEBUG`, `QUIZ`, `COACH`, etc.) with Socratic guidance, multi-turn history, session export, and voice interaction.
- **Verified Credentialing**: Evidence Locker for documenting proof-of-work + tamper-evident certificate generator with a public verification portal (`/verify-certificate`).
- **Global Command Palette**: Instant navigation across all modules and tools via `⌘K` / `Ctrl+K`.

---

### Technical Architecture & Readiness
- **Stack**: Modern React 19, TypeScript 5.8, Vite 6, Node.js, Express 4, Tailwind CSS.
- **Persistence & Auth**: Firebase Authentication + Firebase Firestore with strict UID-based data isolation.
- **AI Infrastructure**: Decoupled AI provider router (Google Gemini Free Tier default) with deterministic offline fallback for 100% uptime.
- **QA Verification**: **38 test files, 362 tests passing (100% pass rate)** with zero TypeScript compiler errors.
